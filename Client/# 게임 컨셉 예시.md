# 게임 컨셉 예시

* 장르: 라운드 기반 뱀서 라이크

* 구조:

  1. 전투 라운드 시작
  2. 적 웨이브 등장
  3. 생존 완료
  4. 상점 진입
  5. 무기/패시브 구매
  6. 다음 라운드

* 특징:

  * 10라운드마다 보스
  * 후반으로 갈수록 “물량 + 특수능력 조합”
  * 플레이어는 매 라운드 종료마다 성장
  * 한 판 목표: 30라운드 클리어

---

# 적 타입 설계

## 기본 스탯 규칙

* HP = 체력
* SPD = 이동속도
* DMG = 접촉 피해
* XP = 경험치
* Weight = 스폰 비율 가중치

# 라운드 설계 철학

## 초반 (1~5)

* 플레이어 빌드 형성
* 약한 물량

## 중반 (6~15)

* 빠른 적 + 탱커 혼합
* 회피 압박 시작

## 후반 (16~25)

* 특수능력 적 증가
* 원거리 + 돌진 조합

## 엔드게임 (26~30)

* 화면 압박
* 엘리트 다수
* 생존 중심

# 추가로 확장하기 좋은 시스템

* 엘리트 몬스터 접두사

  * 폭주
  * 재생
  * 분열
  * 순간이동

* 이벤트 라운드

  * 골드 러시
  * 저주 웨이브
  * 보물 고블린

* 무기 진화 시스템

  * 특정 패시브 조합 시 진화
  * 예:

    * 화염방사기 + 연료탱크 = 헬파이어
    * 리볼버 + 관통탄 = 매그넘 리퍼

원하면 다음 단계로:

* CSV/JSON 형태 데이터 테이블
* 언리얼 DataTable 구조체 설계
* 웨이브 스폰 알고리즘
* 무기 진화표
* 난이도 커브 수식
* 플레이타임 기준 밸런싱
* 로그라이크 메타 성장 시스템
  까지 이어서 설계해줄 수 있어.
